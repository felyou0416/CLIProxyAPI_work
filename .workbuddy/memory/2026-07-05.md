## 面板首页指示灯状态缓存机制

- **问题**: 每次打开面板，指示灯都从默认红色闪烁到真实状态
- **方案**: localStorage 持久化 6 个指示灯（proxy/openclaw/ip-helper/dashboard/oauth/tunnel）的上次状态
- **实现** (`status.js`):
  - `loadIndicatorStates()` — 从 `cli-indicator-states` 读缓存并立即应用到 DOM
  - `saveIndicatorStates()` — 扫描 DOM 中所有指示灯当前颜色写入 localStorage
  - `refreshStatus()` 完成所有 updateIndicator 后调用 saveIndicatorStates
  - `handleActionWithIndicator()` 操作失败时也保存错误状态
- **boot.js** 修复:
  - `showSection()` 改为 `await showSection()` — 之前缺少 await 导致 HTML 未渲染完就执行 loadIndicatorStates
  - `await showSection()` 之后调用 `loadIndicatorStates()`，再 `await refreshStatus()`
- **版本号**: `status.js?v=20260705-indicator-cache`, `boot.js?v=20260705-indicator-cache`
- **文件**: `index.html`, `js/status.js`, `js/boot.js`
