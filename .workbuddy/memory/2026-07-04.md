## 修复聊天页面无法加载可选模型

- **问题**: 聊天页面 `chat.js` 的 `chatFetchJson()` 没有携带认证 token，Dashboard 密码认证启用后所有 API 返回 401
- **对比**: `core.js` 的 `api()` 函数正确携带了 `Authorization: Bearer <token>`，但 `chat.js` 用的是裸 `fetch()`
- **修复**: 在 `chatFetchJson()` 中：
  1. 从 `getAuthToken()` (localStorage) 读取 token，加入 `Authorization` header
  2. 401 时调用 `clearAuthToken()` + `showLoginScreen()`，与 `core.js` 行为一致
- **影响范围**: `chatFetchFirstJson()` 内部调用 `chatFetchJson()`，自动继承修复
- **文件**: `CLIProxyAPI-Dashboard/js/chat.js` 行 142-172
