# 2026-07-16

## 精简端口绑定：移除 Access Gateway，Core 直接监听 8317

- **背景**: 原来双端口架构 Core(8318) ← AccessGateway(8317) ← 客户端，AccessGateway 只做了一层模型白名单过滤，实际不必要
- **改动** (`CLIProxyAPI-Dashboard/backend/processes.py`):
  1. `core_proxy_port()` 返回值从 8318 改为 8317
  2. 移除 `start_proxy()` 中 Access Gateway 二进制文件存在性检查
  3. "已运行"检查不再判断 gateway 进程
  4. 端口循环 `(8317, 8318)` → `(8317,)`
  5. Core 的 `bind_host` 从硬编码 `'127.0.0.1'` 改为使用 `bind_host` 变量（支持 LAN 暴露到 `0.0.0.0`）
  6. 删除整个 Access Gateway 启动代码块
  7. 删除 `stop_proxy()` 中 gateway kill 逻辑
  8. 清理未使用的 import: `ACCESS_GATEWAY_ROOT`, `ACCESS_GATEWAY_BINARY`, `ACCESS_GATEWAY_STDOUT`, `ACCESS_GATEWAY_STDERR`
- **无需改动**: `tools.py`、`terminals.py`、`auth.py` 原本就用 8317，保持不变
- **影响**: 重启 Dashboard 后 Core 直接绑定 8317，不再依赖 AccessGateway 二进制
