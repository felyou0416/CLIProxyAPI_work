本地统一入口

先确认模型，再把外部程序接到同一个 Base URL。

默认基础地址是 http://127.0.0.1:8317。如果开启暴露模式，就把主机名替换成面板里显示的暴露地址。

Base URL
http://127.0.0.1:8317
DOC

路由预览

输入本机调用时填写的 model ID，例如 openrouter-free，查看 storage/auth 当前会命中哪些认证，以及是否按 round-robin 轮询。


    


    

      

        
GET

        
/v1/models

      

      

        http://127.0.0.1:8317/v1/models
        
      

      
查看当前代理实际可调用的模型 ID。先查这个，再决定外部程序里 `model` 填什么。

      
适用

      
所有 provider 通用。最适合排查“面板显示”和“真实可调用”是否一致。

    


    

      

        
POST

        
/v1/messages?beta=true

      

      

        http://127.0.0.1:8317/v1/messages?beta=true
        
      

      
Claude / Anthropic 风格接口。适合 Claude 类客户端，`minimax-portal` 也建议优先走这条。

      
最小请求体

      
{
  "model": "openrouter-free",
  "max_tokens": 256,
  "messages": [
    { "role": "user", "content": "Say OK only." }
  ]
}

    


    

      

        
POST

        
/v1/responses

      

      

        http://127.0.0.1:8317/v1/responses
        
      

      
OpenAI Responses 风格接口。适合新式 OpenAI SDK 或支持 `responses` 的外部程序。

      
最小请求体

      
{
  "model": "codex-gpt-5.4",
  "input": "Say OK only."
}

      
注意

      
`minimax-portal` 走这条时，`input` 最稳的是数组结构，不建议只传纯字符串。

    


    

      

        
POST

        
/v1/chat/completions

      

      

        http://127.0.0.1:8317/v1/chat/completions
        
      

      
OpenAI Chat Completions 风格接口。兼容面最广，很多现成工具默认都走这条。

      
最小请求体

      
{
  "model": "aihubmix-gpt-4.1-free",
  "messages": [
    { "role": "user", "content": "Say OK only." }
  ],
  "max_tokens": 256
}
