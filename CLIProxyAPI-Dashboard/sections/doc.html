本地统一入口

先确认模型，再把外部程序接到同一个 Base URL。

默认基础地址是 http://127.0.0.1:8317。如果开启暴露模式，就把主机名替换成面板里显示的暴露地址。

Base URL
http://127.0.0.1:8317
DOC 路由预览

输入 Model ID，查看当前请求将命中哪些认证与轮询规则。


      

    


    
    

      

        GET
        /v1/models
        
      

      

        
获取当前代理所有可用和已注册的模型 ID 列表。

      

    


    
    

      

        POST
        /v1/chat/completions
        
      

      

        
OpenAI 聊天会话接口，兼容绝大多数标准客户端。

        

          展开示例 Payload
          
{
  "model": "agnes-agnes-2.0-flash",
  "messages": [
    { "role": "user", "content": "Hello" }
  ]
}

        

      

    


    
    

      

        POST
        /v1/images/generations
        
      

      

        
OpenAI 图像生成接口（系统根据模型名称如 image/dall-e/flux/cogview 自动归类为生图模型）。

        

          展开示例 Payload
          
{
  "model": "agnes-image-2.0-flash",
  "prompt": "a beautiful forest",
  "size": "1024x1024"
}

        

      

    


    
    

      

        POST
        /v1/messages?beta=true
        
      

      

        
Claude / Anthropic 消息接口，供 Anthropic 系列客户端使用。

        

          展开示例 Payload
          
{
  "model": "claude-sonnet-4-5",
  "max_tokens": 256,
  "messages": [
    { "role": "user", "content": "Hello" }
  ]
}

        

      

    


    
    

      

        POST
        /v1/responses
        
      

      

        
OpenAI Responses 助理流式响应接口。

        

          展开示例 Payload
          
{
  "model": "codex-gpt-5.4",
  "input": "Hello"
}

        

      

    


    
    

      

        POST
        /v1/videos/generations
        
      

      

        
视频生成接口（系统根据模型名称包含 video 自动归类为视频模型，支持原生的 /v1/videos 或 /v1/videos/generations）。

        

          展开示例 Payload
          
{
  "model": "agnes-agnes-video-v2.0",
  "prompt": "a beautiful forest",
  "size": "1280x704"
}

        

      

    


    
    

      

        GET
        /v1/videos/:request_id
        
      

      

        
视频生成任务状态与结果查询接口（将 :request_id 替换为生成请求返回的 id 或 task_id）。
