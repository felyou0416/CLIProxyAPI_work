数据导入导出

导出当前全部配置用于备份或迁移，或从导出文件恢复。包含以下数据：

认证 & 密钥
  • 认证文件 (OAuth / API Key 凭证)
  • 虚拟 API Key (密钥管理)
  • API Key 列表 (api-keys 配置)
模型配置
  • 运行时配置 (active config, 含 provider / alias / openai-compatibility)
  • 模型映射覆写 (provider_model_overrides)
  • 聚合模型别名 (aggregate_model_aliases)
  • 模型代理设置 (model_proxy_settings)
  • Thinking 配置 (model_thinking_configs)
系统配置
  • 基础配置文件 (base-config.yaml)
  • 认证源配置 (sources.json)
  • 面板设置 & 运行时状态 (state.json)

导出数据

导出上述所有数据到一个 JSON 文件中。
